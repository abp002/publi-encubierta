# publi-encubierta

¿Qué fracción del contenido en español de TikTok con marcadores comerciales no declara
la relación publicitaria? Estudio estadístico (nunca un señalamiento) sobre el dataset
público `kuben-developer/tiktok-videos-4b`, con PU learning y una cascada barata → cara.

El proceso completo, con decisiones y descartes, está en [`NOTEBOOK.md`](NOTEBOOK.md).

Este repo no contiene datos ni los contendrá. Ver `CLAUDE.md` para las reglas.
